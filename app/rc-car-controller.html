Connection settings & help
HC-05 is Bluetooth Classic — a web page cannot talk to it.
• To use this page, swap the HC-05 for a BLE module (HM-10 / AT-09 / JDY-08) — the Arduino firmware stays the same.
• Android: open in Chrome and allow Bluetooth. iOS: use the Bluefy browser.
• Or choose USB cable and plug the Arduino into the phone with an OTG adapter.
• The baud box above is only used for the USB transport.
